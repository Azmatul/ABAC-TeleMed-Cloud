# Telemedicine ABAC — Full UI (Local + Testnet)

This is a ready-to-run React (Vite + Tailwind) front-end for your Telemedicine ABAC project.

## Features
- Login page (MetaMask)
- Registration (Doctor/Patient) → pending queue (localStorage demo)
- Admin panel → approve registration → on-chain `grantRole`
- Role-based dashboards (Patient/Doctor/Admin)
- Works on **localhost** and **Sepolia** via `.env`

## Setup
```bash
npm i
# pick one:
copy .env.local.example .env.local
copy .env.sepolia.example .env.local
```

Edit `.env.local` if needed:
```
VITE_CHAIN="localhost"
VITE_LOCAL_RPC_URL="http://127.0.0.1:8545"
# (optional) VITE_CONTRACT_ADDRESS="0x..."
```

### ABI & Address
Place these (generated by your Hardhat `deploy.js`) into:
```
src/lib/abi.json
src/lib/contract-address.json  # {"address":"0x...."}
```

## Run
```bash
npm run dev
```

## Notes
- For Sepolia, set `VITE_CHAIN="sepolia"` and `VITE_SEPOLIA_RPC_URL`.
- Admin approval requires the connected wallet to have `DEFAULT_ADMIN_ROLE` in your contract.
- Replace `src/lib/registry.js` with API/contract storage for real registration queues later.
